# Best Place to Live 🌍

A data-driven web application that helps users explore and compare cities around the world based on factors such as language diversity and sunshine hours. This project aims to help individuals find the ideal place to live depending on cultural, linguistic, and environmental preferences.

## 🌟 Features

- 📊 **Language Diversity Insights**: Compare official, regional, minority, national, and widely spoken languages in different countries and regions.
- 🌞 **Sunshine Data Visualization**: Explore average annual sunshine hours for various African cities (with potential to expand).
- 🗺️ **Interactive Interface**: Intuitive layout for easy comparison and exploration.
- 🧠 **Data-Driven Decisions**: Uses real datasets to provide meaningful insights into lifestyle and environmental factors.

## 🛠️ Tech Stack

- **Frontend Framework**: [Next.js](https://nextjs.org/)
- **Styling**: CSS Modules / Tailwind / Custom CSS (to be finalized)
- **Data Handling**: CSV/JSON parsing and chart libraries
- **Version Control**: Git & GitHub

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v16+)
- npm or yarn

### Installation

1. Clone the repository:

    ```
    git clone https://github.com/shinymcshine09/best-place-to-live.git
    cd best-place-to-live

3. Install dependencies:

    ```
    npm install

or

    yarn

3. Run the development server:

    ```
    npm run dev

or

    yarn dev

4. Open your browser and visit:

    ```
    http://localhost:3000
